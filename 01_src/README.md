# Erasom Lobby - Agregador social de redes

## Identificador de la aplicación
- applicationId: `erasom.lobby`

## Cómo abrir
1. Abre Android Studio.
2. Selecciona "Open" y busca la carpeta:
   `D:\Antigravity\erasomlabs\erasom.lobby\01_src`
3. Espera a que Gradle sincronice.
4. Conecta un dispositivo Android o inicia un emulador.
5. Haz clic en Run (▶).

## Funcionalidades
- Grid de 15 redes sociales con iconos emoji
- Panel selector para mostrar/ocultar cada red
- Persistencia de preferencias en SharedPreferences
- Al tocar un icono, abre la red social correspondiente
- Diseño con efecto de colores pastel suaves

## Notas
- AdMob se puede agregar cuando tengas el ID.
- La firma de la APK debe usar la misma upload key de Google Play.
